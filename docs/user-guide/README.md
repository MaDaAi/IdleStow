# IdleStow user guide

IdleStow finds files you have not used for a while and compresses them losslessly, with every change
verified and reversible. It never deletes your files on its own: the only deletions are ones you ask
for in Recovery, such as removing a retained original after its retention period.

Start with the first guide if you are new. Use the troubleshooting guide when something looks wrong.

| Guide | Read it when |
|---|---|
| [Getting started](getting-started.md) | You are installing IdleStow, going through setup, or want to understand the screens and settings. |
| [Recovery](recovery.md) | You want to undo an optimization, restore an archived file, or get files back without IdleStow. |
| [Troubleshooting](troubleshooting.md) | A folder is refused, a feature is unavailable, a dialog appears, or you need the log files. |

Related documents:

* [Platform compatibility](../platform-compatibility.md): which Windows versions and file systems are supported and tested.
* [Known issues](../development/KNOWN_ISSUES.md): limitations that are known and documented.

Read this before you rely on IdleStow: **compression is not a backup**. Keep your own backups of anything
important.
